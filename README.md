# GuruShirt — 2D & 3D Interactive Apparel Design Studio

GuruShirt is a Next.js + TypeScript + Three.js interactive clothing design studio running on `http://localhost:3005`.

## Features (Phase 1 & Phase 2)
- **Single-View Studio with Unified Expandable Bottom Tool Dock** (`2D Pattern View` & `3D Studio View`)
- **7 Supported Clothing Types:** Boxy T-Shirt, Heavyweight Hoodie, Athletic Tank Top, Winter Puffer Jacket, Streetwear Pants, Mesh Shorts, and Crew Socks
- **Graphic & Typography Engine:**
  - Import custom graphics (`PNG`, `JPG`, `SVG`, `WebP`) + persistent Uploaded Designs library
  - Live Custom Text & Arched Typography generator
  - Single-Color Screenprint Stencil converter, Auto-Remove Background, Color Invert, Colorize Tint, and Ink Blend Modes
  - Step-and-Repeat Multiply Pattern Tiling & 8 Shape Cutout Masks (`Rect`, `Circle`, `Arch`, `Diamond`, `Star`, `Shield`, `Pill`, `Hex`)
  - Physical Connected-Fabric-Piece 360° Seam Wrapping (`Front <-> Back` torso continuity without bleeding onto separate sleeve or collar pieces)
- **Digital Wardrobe Closet:** Save, filter, reload, duplicate, and export custom garments

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3005](http://localhost:3005) in your browser.
